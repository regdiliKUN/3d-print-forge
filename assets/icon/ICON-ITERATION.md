# 3D Print Forge 图标迭代记录

> 对象：桌面「3D 打印建模工具」快捷方式图标
> 轮次：34 轮（要求 ≥20 轮），每轮都有参数变更、量化指标和成品留档
> 工具：`tools/icon_forge.py`（参数化绘制 + 自动评估，可复现）
> 产物：`assets/icon/`（多尺寸 ICO、PNG 预览、逐轮留档、指标 JSON）

---

## 一、设计语义

程序叫 **3D Print Forge**，图标必须同时说清两件事：**3D 打印** + **Forge（锻造/成型）**。

| 元素 | 含义 | 做法 |
|---|---|---|
| 等距立方体 | 打印出来的零件 | 2:1 等距投影，顶/左/右三面受光不同 |
| 横向层纹 | 逐层堆叠的打印过程 | 等距投影下水平切面是 V 形折线，按面提亮 |
| 悬空打印头 | 正在打印，而不是摆着的积木 | 两段式喷头悬浮于零件上方 4~6% |
| 耗材丝 | 把「喷头」和「零件」连成一个动作 | 从喷头尖端到顶面的一条渐隐竖线 |
| 锻造火花 | Forge，全图唯一暖色 | 右上角橙色四角星 + 2 颗卫星点 |
| 外描边 | 深色桌面可读，更要浅色桌面可读 | 3% 青绿渐变环 + 小尺寸补偿 |

配色全部取自界面 `static/style.css`，不引入第二种绿：

| 用途 | 色值 |
|---|---|
| 主色 / 耗材 | `#5DCAA5` |
| 顶面亮 | `#9EF0C8` |
| 右面中 | `#1E9E76` |
| 左面暗 | `#0D644E` |
| 底板 | `#162024 → #05070B` |
| 锻造火花 | `#F3A329` |

## 二、方法：不靠「感觉好点了」

每轮都跑同一套评估，输出 5 个可比较的数：

| 指标 | 含义 | 期望 |
|---|---|---|
| `worst_edge` | 图标轮廓带的平均亮度，与**深色**（#0A0C10）和**白色**桌面背景亮度差的**较小值**。等价于「最差背景下轮廓有多清楚」 | 越大越好，>100 为佳 |
| `sep` | 主体最亮 10% 与最暗 10% 的亮度差，反映立体层次 | 越大越清楚 |
| `detail16` | 16×16 图的梯度能量，反映小尺寸还剩多少细节 | 适中（过高=噪点） |
| `fidelity` | 256px 降采样到 16px 与「原生绘制 16px」的 RMSE 归一化。衡量小尺寸是否还长得像大图 | 越高越好 |
| `presence16` | 16px 下主体像素占比 | 0.5~0.65 之间最稳 |

关键判据是 `worst_edge`：它一次回答「深色桌面」和「浅色桌面」两个场景。

## 三、五个阶段

**阶段一（R01–R05）打骨架。** 先三层「悬浮板」表达逐层堆叠，修掉首版层厚+层距之和超出画布的问题；
第 5 轮加外描边，`worst_edge` 从 8.9 跳到 115——这一跳说明：**深色图标在浅色桌面上，没有外圈就是一块模糊的深色斑**。

**阶段二（R06）设计反转。** 三层悬浮板在 32px 以下会粘成一坨，`fidelity` 只有 0.607。
改成**实心立方体 + 等距层纹**，轮廓完整、层纹退为细节，`fidelity` 立刻升到 0.83。

**阶段三（R07–R20）加元素、调配色。** 依次加入层纹密度、打印头、耗材丝、锻造火花；
每加一个元素 `fidelity` 都会掉一点（细节变多），这是必然的权衡，所以同时用小尺寸简化策略抵消。

**阶段四（R21–R25）目检回归。** 表格指标好看不等于图好看。人工看图发现两个硬伤：
① 打印头压在顶面内且与顶面几乎同色——**视觉上根本不存在**；
② 层纹是单一浅色线，既淡又像「一叠纸」。
于是把喷头改成悬浮 + 冷青灰，层纹改成「按面提亮」的浮雕线。

**阶段五（R26–R34）收敛。** 外框从 5% 收到 3%（原本像绿色相框，压过主体）；
等距比 0.50→0.38 让块体「立起来」；最后两轮专攻 16px：主体退让 6%、层纹降到 3 条加粗、外环补偿 1.55×。

## 五、终版各尺寸检查

| 尺寸 | 用途 | 检查结论 |
|---|---|---|
| 256×256 | 资源管理器大图标 / 详情页 | 顶面渐变、6 条层纹、喷头、火花全部清晰 |
| 128×128 | 中图标 | 层纹开始并线但仍可分辨 |
| 64×64 | 列表视图 | 三面明暗分明，喷头与丝连成一条竖线 |
| 48×48 | 小图标（默认桌面 DPI 100%） | 层纹 4 条，火花仍在 |
| 32×32 | 小图标 / 任务栏 | 自动切简化版：去火花与耗材丝，层纹 4 条加粗 |
| 16×16 | 详细信息 / 标题栏 | 主体退让 6%、层纹 3 条、外描边 1.55× 补偿，仍是「绿色块 + 白点」可辨 |
