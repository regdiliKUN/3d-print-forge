# bench 套件 21 轮迭代记录

对第一版基准套件（`make_models` / `run` / `worker` / `stages` / `digest` / `verify_raycast` / `compare` / `audit_thresholds` / `check_models` + `OPTIMIZATION.md`）做的 21 轮迭代。每轮锁定一个质量维度，改动后自检目标是否达成。核心需求（可复现基准、结果指纹防算错）与整体结构保持稳定，无凑数式修改。

> 标注：**R1–R10** 来自上一阶段（已提交 `244feb6`），本文件接续 **R11 起**至 **R21**；为完整起见也列出 R1–R10 的摘要。

## R1 正确性 —— 模型集 ↔ 清单自检（`check_models.py`）
新增脚本：校验磁盘模型与 `model_manifest.json` 的面数/顶点数/体积/表面积/包围盒一致。生成器一改、模型悄悄变了，历史曲线就断了。
**自检**：立刻抓到 2 处真实漂移（overhang_t 顶点 294→292、degenerate 面 3→2，焊接与退化剔除造成），已对账。

## R2 完整性 —— 清单改记「落盘再回读」的几何
R1 比的是「生成时内存几何」，但基准测的是「落盘再读回」的几何（顶点焊接、退化面剔除后不同）。清单改为记录后者，避免假一致。
**自检**：重建清单后 R1 复检 13/13 一致。

## R3 边界 —— `make_models.py` 补 `sys.path`
直接当脚本跑时找不到 `app` 包而崩溃。补 `sys.path.insert`。
**自检**：独立 `python bench/make_models.py` 不再报错。

## R4 完整性 —— 结果对比器（`compare.py`）
基准能采数、能判过/不过，但答不出「这两次之间到底变了什么」。新增耗时/内存/指纹三方对比。
**自检**：对比优化前后，清晰显示 8.72×/20.95× 与 0 指纹变化。

## R5 可读性 —— 变化列统一
`compare` 的「变化」列原本混写 `1.06x`/`1.06x快`。改为「快 1.4x / 慢 1.1x / 持平」，倍数与方向分开。
**自检**：输出列格式统一，噪声抖动显示「持平」。

## R6 可读性 —— `run` 表格阈值内联
原表格阈值单列两列、中文挤乱。改为阈值内联到实测值后（`27ms (限300)`），去掉重复列。
**自检**：表格清爽，列宽稳定。

## R7 一致性 —— 阈值回落默认显式标注
阈值缺失时静默回落 `default`，会让「PASS」看起来成立实则未定义。改为显式标「默」并列出未定义项。
**自检**：overhang_t/thick_field 此前静默 PASS，现明确标注「默 2000ms」。

## R8 一致性 —— 阈值审计（`audit_thresholds.py`）
阈值表与阶段矩阵独立维护，容易脱节。审计两类坏状态：矩阵项缺专属阈值（假 PASS）、阈值过松/过紧。
**自检**：44 项矩阵全部有专属阈值；发现 6 条过松（R19 收口）。

## R9 边界 —— 新增 `empty`（0 面）与 `needle`（长宽比 1000:1）极端模型
模型集只有常规件与故障件，缺最易暴露几何破绽的极端形态。纳入基准矩阵。
**自检**：`make_models` 生成成功；两模型进入 MATRIX。

## R10 正确性 —— 修复空模型被评 A/93「可以直接打印」
0 面空模型七项检测项项「无问题」（没边可断、没面可反），评分 A/93 给出错误安全结论。在 `quality_score` 前加空模型闸门，改为 D/0。
**自检**：empty 从 A/93 → D/0；其余 4 模型评分不变。

## R11 完整性 —— `verify_raycast` 加入 `needle`（1000:1 针）
验证器 10 个模型里没有新加的极端形态，而针正是最易让射线裁剪 slab 法露怯的几何。
**自检**：needle 加入后 24 用例全部逐位一致。

## R12 性能 —— `run` 支持并行执行（`--parallel N`）
全量串行 ~80s，迭代太慢。加并行，但显式告警「并行争 CPU、耗时与串行不可比」并记入结果文件。
**自检**：2 模型 2 重复，并行墙钟明显低于串行；结果文件记 `env.parallel`。

## R13 一致性 —— 环境指纹 + `compare` 跨环境报警
结果只记 Python 版本，阈值却按机器定的。加环境指纹（CPU/内存/关键库版本/并行度），`compare` 在跨环境对比时直接报警。
**自检**：冒烟确认指纹写入；compare 对 `parallel` 不同输出告警。

## R14 健壮性 —— `worker` 网格加载失败不杀进程
加载在 try 之外，一旦失败整 worker 死掉、丢失该模型所有阶段结果。改为在 try 内捕获、按阶段记错误并 break。
**自检**：正常阶段无回归（ball_20k/analyze 243ms）。

## R15 正确性 —— `analyze` 指纹加 `verdict`
R10 给质量评分加了 `verdict` 字符串，但 `st_analyze` 摘要没包含它，verdict 退化不会被指纹捕获。补上。
**自检**：指纹 schema 含 `verdict`；重生成回归基线。

## R16 正确性 —— `verify_raycast` 加厚度场聚合摘要自洽检查
逐射线比对只覆盖核心求交，没覆盖生产入口 `thickness_field` 的聚合层（min/max/p5）。若有人把 p5 误改 p50 或字段拼错，verify 完全抓不到。新增 `check_summary_invariants`：断言 `min=values.min`、`max=values.max`、`p5≈真实5分位`。
**自检**：10 模型全部聚合自洽，退出码 0。

## R17 完整性 / CI —— 一键门禁（`ci.py`）
把「基准（阈值+指纹回归）+ 射线一致性 + 阈值审计」串成 CI 可直接调用的入口，聚合退出码；`expected.json` 缺失则视为未就绪而失败（避免删了基线还以为绿）。
**自检**：串行快检三道闸门全绿；并行快检因争 CPU 触发阈值告警 → 证明门禁有效。

## R18 可读性 / 文档 —— `bench/README.md`
套件此前无使用文档。补齐：一条命令重建环境、日常命令表、各脚本职责、两个必知坑（并行不可比 / 环境指纹）。
**自检**：文档可读、命令可复制执行。

## R19 一致性 —— 审计收口
原审计用 `latest.json`（可能是并行/快检脏数据），且把 39 条重操作/导出的安全上限一律标「过松」导致 CI 永远红。改为：优先读 `expected.json`；子毫秒操作（实测 0ms）不判过松（比值被 0 撑成无穷，纯噪声）；收紧 6 条交互路径过松阈值（overhang_t/needle 的 analyze/thick_field/build_supports/support_density）；「过松」降级为调优建议、不阻断 CI，仅「缺定义/过紧」算失败。
**自检**：审计返回 0 阻断项，过松 39 条为建议；`thresholds.json` 补「宽松上限意图」说明。

## R20 一致性 —— `check_models` 四源一致性
原只校验「模型 vs 清单」。新增矩阵 ↔ 清单 ↔ 磁盘文件 ↔ 阈值表 四方互校，任一脱节即报错。
**自检**：13/13 模型与清单一致；四方完全对得上。

## R21 汇总 —— 迭代记录 + 引用
产出本文件；在 `OPTIMIZATION.md` 增加指向本记录的章节。**初始版本 → 最终版本整体提升：**

| 维度 | 初始 | 最终 |
|---|---|---|
| 模型集 | 11 个，缺极端形态 | 13 个，含 0 面空模型与 1000:1 针 |
| 结果指纹 | 不含 `verdict`、空模型可假优 | 含 `verdict`；空模型闸门杜绝假 A 评分 |
| 阈值判定 | 缺阈值静默 PASS | 缺阈值显式标注「默」+ 审计拦缺定义 |
| 跨环境 | 仅记 Python 版本 | 完整环境指纹 + 跨环境对比报警 |
| 执行效率 | 仅串行 ~80s | 支持并行（含不可比告警） |
| 验证深度 | 仅逐射线距离一致 | 加厚度场聚合摘要自洽检查 |
| 健壮性 | 加载失败杀进程 | 按阶段记录错误 |
| CI 集成 | 无 | `ci.py` 串联三闸门，缺基线即失败 |
| 文档 | 无 | `bench/README.md` + 本迭代记录 |
| 数据一致性 | 模型 vs 清单 | 矩阵/清单/磁盘/阈值 四源互校 |

**修复的真实缺陷（非性能）**：空模型被质量评分判为 A/93「可以直接打印」（R10）；阈值缺失静默假 PASS（R7）；审计用脏数据（R19）；加载失败丢失整模型结果（R14）。

**仍待办（非本轮范围）**：间歇性 `analyze` 崩溃未闭环（疑似并发改文件导致导入半成品，需协调另一会话）；`skimage` 在 numpy 2.5 下 DeprecationWarning（下大版本会崩）。
